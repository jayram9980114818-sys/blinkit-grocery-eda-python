Python EDA of BlinkIT grocery sales data: data cleaning, category, outlet and location analysis, correlations, and business recommendations.

# BlinkIT Grocery Sales Analysis

Exploratory data analysis of a BlinkIT grocery sales dataset (8,523 records, 10 outlets, 16 product categories) done in Python and Jupyter Notebook.

## What this project covers
- Data quality checks and cleaning (missing values, duplicates, inconsistent labels, outliers)
- Overall sales and customer rating analysis
- Sales by product category, fat content, outlet type, outlet size and location tier
- Correlation of sales with item visibility, weight, rating and outlet characteristics
- Top 25% versus bottom 25% performance comparison
- Improvement areas and practical business suggestions

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Jupyter Notebook

## Files
- `blinkit.ipynb`: full analysis notebook
- `BlinkIT_Grocery_Sales_Report_*.pdf`: 12-page business analytics report

## Note
This is a sample dataset. The sales unit is not stated, and there is no date or cost data, so the analysis does not cover time trends or profitability.
